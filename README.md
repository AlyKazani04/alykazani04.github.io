# Aly's Portfolio Site

A hand-made, pure HTML and CSS portfolio site with no added flashiness or style (for that matter, yet...).

## Build it yourself

#### 1. Clone it

```
git clone git@github.com:AlyKazani04/alykazani04.github.io.git
```

#### 2. Install Dependencies

```
npm install
```

#### 3. Build it

```
npm run build
```

and find the built files ready to view in `dist/` or just use vscode's live server to view the static site without building it.
